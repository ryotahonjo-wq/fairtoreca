応募の約束

転売のない抽選を、みんなで
  1. 公式ページから応募リンクは各ショップの公式ページです。代行や非公式のフォームは使わない。
  2. 1人1口を守る家族やサブアカウントでの重複応募はしない。当たる人が増えるのは、みんなが守ったとき。
  3. 転売目的で応募しない遊ぶ・集める人のための抽選です。高額な転売品も買わないことが、定価で買える近道。
  4. 当たったら期限内に購入キャンセルは次の人のチャンスを減らします。支払い方法と期限を先に確認しておこう。
